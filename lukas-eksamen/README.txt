Snake Game med registrering av brukere, login side, highscore saving og en avlogget versjon.

Spillet er satt opp på en lokal server på skolen med en MySQL database for å lagre data.

For å spille spillet må du endre directory med "cd /var/www/eksamen/lukas-eksamen", deretter må du aktivere det virtuelle miljøet med "source env/bin/activate". Når miljøet er aktivert, må du starte spillet med "python3 app.py". spillet burde være oppe på http://127.0.0.1:5000 om du gjorde stegene riktig

Spillet lar brukere lagre sensitive opplysninger som alder, nationalitet og bosted(by).

Programmer brukt: MySQL, Python3, HTML, CSS, JavaScript, Flask, VSCode
